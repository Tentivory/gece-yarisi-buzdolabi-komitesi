# Gece Yarısı Buzdolabı Komitesi

> **Resmî tanım:** Saat 03:00 ile 04:30 arasında, ayakları çıplak bir vatandaşın buzdolabı kapağını açması üzerine kendiliğinden teşekkül eden, tüzel kişiliği tartışmalı, yetkisi ise tartışmasız kurul.

Bu yazılım, insanlığın en kadim sorununu çözer: *“Bu saatte ne yenir?”*

Cevap komitededir. Komite ise Python 3’tedir. Yani aslında cevap `print` fonksiyonundadır ama bunu toplantı tutanağında yazmayız.

## Kuruluş Gerekçesi

- Mutfak aydınlatması, gece vakti, bir parlamento salonu kadar ciddiyet taşır.
- Yoğurt kapağındaki su damlası, muhalefetin gözyaşı değildir. Sadece yoğurt kapağındaki su damlasıdır. (Komite bunu oy birliğiyle kayda geçirmiştir.)
- Peynir köşesi her zaman “ben buradayım” der. Komite bunu lobi faaliyetleri kapsamında değerlendirir.

## Kurulum

```bash
python3 komite.py
```

Bağımlılık yoktur. Çünkü gece 03:17’de `pip` çalıştırmak, komitenin iç tüzüğüne aykırıdır.

## Kullanım

Program şunları yapar:

1. Buzdolabındaki artıkları (hayalî) envantere alır.
2. Her ürün için bir konuşma metni üretir.
3. Oylama yapar.
4. Kararı ilan eder.
5. Sana “afiyet olsun” demez. Çünkü komite duygusal değildir.

Örnek çıktı:

```
[BAŞKAN] Oturum açıldı.
[SUCUK] Ben hâlâ duruyorum. Bu bir duruştur.
[SALATALIK] Ben suluyum, yani nötrüm.
KARAR: yarım dilim ekmek + sucuk bakışı
```
